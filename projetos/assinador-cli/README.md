# Assinatura CLI

CLI para simulação de assinatura digital via `assinador.jar`.

## 🚀 Como usar

```bash
assinatura version
```

## 📦 Download

https://github.com/gabrielmmendes/assinatura/releases

## 🧱 Estrutura

- cmd/ → comandos CLI
- internal/ → lógica interna
- projetos/assinador-java → serviço Java

## 🔧 Tecnologias

- Go 1.25
- Cobra CLI
- Java 21
